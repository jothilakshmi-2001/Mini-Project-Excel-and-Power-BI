Retail Store Performance
Project Overview

This project focuses on analyzing retail sales data using Microsoft Excel and Power BI. The project covers data cleaning, data transformation, descriptive analysis, Pivot Table analysis, interactive reporting, and dashboard creation.

The main objective is to understand sales, profit, store and manager performance, and customer and order behavior and present meaningful business insights through interactive visualizations.

Problem Statement

The project aims to analyze retail sales and profit performance across different product categories, stores, cities, and regions. It also focuses on understanding customer and order behavior through order status, payment methods, discounts, and customer ratings.

The analysis helps identify high-performing and low-performing areas and provides a clear view of overall retail business performance through Excel analysis and an interactive Power BI dashboard.

Power BI Reports

The analysis was divided into three separate reports based on different areas of the retail sales data.

1. Sales and Profit Overview

This report provides an overall view of sales and profit performance using KPI cards, monthly sales and profit trends, category analysis, and profit-related insights.

2. Store and Manager Performance

This report focuses on store, manager, region, state, and city-level performance to understand variations in business performance.

3. Customer and Order Behavior

This report analyzes order status, customer ratings, payment methods, discounts, and other customer and order-related patterns.
